# 일단

하기 싫은 일을 2분만 시작하게 만드는 개인용 습관 페이지입니다.

페이지: https://sj852.github.io/ildan-web/

- 원할 때 열어서 다음 할 일을 2분 타이머로 시작합니다.
- 할 일마다 색, 타이머 길이, 요일, 순서를 정할 수 있고 오늘만 건너뛸 수도 있습니다.
- 기록은 브라우저에 먼저 저장하고, 토큰을 연결하면 내 비밀 Gist로 기기 간에 동기화합니다.
- 한 번 열어 두면 네트워크가 끊겨도 `sw.js`에 저장된 파일로 열립니다.

토큰은 gist 권한만 체크해서 만들고, 저장소에 올리지 마세요.
